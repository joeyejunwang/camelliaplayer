# Camellia Player

![App Screenshot](s1.png)

A simple, modern Flutter **audio and video player** for **Windows desktop**, **iOS**, and **Web**.
Pick a local MP3 or video file and play. Matching subtitle files in the same folder are loaded automatically.

## Features

- Pick local audio (mp3, wav) or video files (mp4, mkv, webm, mov, …)
- **Drag & drop** an `.mp4` / `.wav` / `.mp3` file anywhere on the home window to start playing (Windows/Web)
- **"Last played" card** remembers the most recent media file; one click replays it
- MP3 playback displays a music icon and filename, with the same playback and lyric controls as video
- Optional subtitle file (SRT, VTT, ASS/SSA) — toggleable overlay
- Native-feeling player UI
- Material 3 light/dark theme (Windows/Web), iOS Cupertino design (iOS)
- **File browser** on iOS to browse and play media files from device storage
- Runs on Windows desktop, iOS devices, and Chrome/Edge web

## Supported Platforms

| Platform | Description |
| --- | --- |
| Windows desktop | Native window with custom title bar, drag & drop support |
| iOS | Cupertino-style UI with native file browser |
| Web | Runs in browser, drag & drop support |

## Prerequisites

| Platform | Required |
| --- | --- |
| Windows desktop | Flutter SDK (3.x) **and** Visual Studio 2022 with the *"Desktop development with C++"* workload |
| iOS | Flutter SDK, Xcode (for building on real device) |
| Web | Flutter SDK + any modern Chromium-based browser |

Verify with:

```bash
flutter doctor
```

If you see `Visual Studio not installed` (Windows), install Visual Studio 2022 Community with the C++ desktop workload, then re-run `flutter doctor`.

## Run

```bash
flutter clean
rmdir /s /q build

# Windows desktop
flutter run -d windows

# iOS simulator
flutter run -d "iPhone 16 Pro"

# Chrome browser
flutter run -d chrome
```

## Build a release executable

### Windows

```bash
flutter build windows --release
# Output: build/windows/x64/runner/Release/
```

### iOS

```bash
# Build for simulator
flutter build ios --simulator --no-codesign

# Build for App Store (requires signing)
flutter build ios --release
# Output: build/ios/iphoneos/Runner.app
```

### Web

```bash
flutter build web
# Output: build/web/
```

## iOS App Distribution

To run on a real iOS device or submit to App Store:

1. Open `ios/Runner.xcworkspace` in Xcode
2. Configure your signing team in project settings
3. For App Store distribution, use Product > Archive

## Platform-Specific Notes

### Windows
- Uses `window_manager` for custom frameless window
- Media playback via `media_kit` for better codec support
- Drag & drop via `desktop_drop` package

### iOS
- Uses native Cupertino widgets for iOS-native look
- File browsing from app's Documents directory
- Media playback via `video_player` package
- File picker for selecting files from other apps

### Web
- Runs in modern browsers with WebAssembly video support
- Drag & drop support
- No custom window management

## Notes

- The `subtitle` package is used as the primary parser; a robust SRT fallback is included if the file format is unusual.
- Audio/video codec support varies by platform:
  - Windows: Uses Media Foundation (H.264/AAC MP4 works out of the box)
  - iOS: Uses AVFoundation (excellent codec support)
  - Web: Depends on browser capabilities

## iOS Setup Troubleshooting

If `flutter run -d iPhone` fails with Xcode errors, follow these steps:

### Missing or corrupted `ios/Runner.xcodeproj/project.pbxproj`
The Xcode project file must be generated by Flutter, not hand-edited as JSON.
On macOS, regenerate it with:
```bash
cd /path/to/camelliaplayer
flutter create --platforms=ios .
```

### "CocoaPods not installed"
```bash
brew install cocoapods
```

### "Main.storyboard could not be opened"
Restore the storyboard from the Flutter template:
```bash
cp /opt/homebrew/share/flutter/packages/flutter_tools/templates/app/ios.tmpl/Runner/Base.lproj/Main.storyboard \
   ios/Runner/Base.lproj/Main.storyboard
cp /opt/homebrew/share/flutter/packages/flutter_tools/templates/app/ios.tmpl/Runner/Base.lproj/LaunchScreen.storyboard \
   ios/Runner/Base.lproj/LaunchScreen.storyboard
```

### "No Material widget found" on iOS
The iOS player screen uses Cupertino widgets only. If you see this error,
replace any Material `Slider` in `lib/ios_player_screen.dart` with
`CupertinoSlider` since iOS uses `CupertinoApp` (no Material ancestor).
